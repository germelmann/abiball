# Jahrbuch-Assets

Lege hier Bilddateien ab (`.png`, `.jpg`, `.jpeg`, `.gif`, `.webp`).
Sie erscheinen automatisch in der Sidebar des Template-Designers
(`/jahrbuch_template_edit`) und können per Klick auf die A4-Seite
gelegt werden — z. B. für Logos, Hintergründe, dekorative Elemente.

Beim Platzieren wird das Bild als Data-URL ins Template eingebettet.
Wird die Datei später ausgetauscht, muss das Element im Designer
einmal neu eingefügt werden, damit die neue Version verwendet wird.
