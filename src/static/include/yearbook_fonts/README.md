# Jahrbuch-Schriftarten

Lege hier `.ttf`- oder `.otf`-Dateien ab. Sie werden beim Öffnen des
Template-Designers (`/jahrbuch_template_edit`) automatisch geladen, im
Schrift-Dropdown der Textelemente angeboten und bei der PDF-Generierung
verwendet.

Die alphabetisch erste Datei wird zur Fallback-Schrift.

Dateinamen ohne Erweiterung werden als Schriftartname benutzt
(`Roboto-Bold.ttf` → `Roboto-Bold`).
